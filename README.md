# palm-launcher

A simple launcher for quickly running a small set of commands.

## Usage

palm-launcher can attach to either hand or controller, it can handle an arbitrary number of commands, tho they may get hard to select at high counts.

```bash
palm-launcher Hand/Left "flatland" "solar-sailer" "hexagon-launcher" "cage firefox"
```

possible mount locations are:
- `Hand/Left`
- `Hand/Right`
- `Controller/Left`
- `Controller/Right`

when pulling the launching cord far enough it will derez anything intersecting wiht it.
